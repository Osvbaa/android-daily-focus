# Contrato UI: Hábitos

El propietario implementa los visuales. Mostrar programación por día civil, nivel Mini/Plus/Elite, racha y puntos persistidos. Eventos: crear/editar/archivar hábito y registrar nivel; una repetición no duplica crédito. El nivel debe tener texto/semántica además de color. Estados vacío, carga, error y hábito no programado deben ser distinguibles. Navegación con `habitId` primitivo. Probar HABIT-01 a HABIT-03, cambio de día y restauración.
